# My words Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 我的 ("My words") reading level that swaps into Chinese only the
words on a list you control. You build the list by importing Anki `.apkg`
decks and by adding or removing words by hand.

**Architecture:**
- **Parsing happens on a new extension page** (`mywords/`): a small zip
  reader, fzstd for zstd, and a read-only SQLite reader. The page saves
  `{ zh, pinyin, en, source }` records through a background message that only
  extension pages may send.
- **The background builds an English → Chinese map** from the list at
  level 0. Each word's English is the card's English plus every CC-CEDICT
  definition for the card's pronunciation. It feeds that map to the existing
  `diglotItem` swap code without changing it.

**Tech Stack:** plain ES modules bundled by esbuild, WebExtension APIs
(Firefox 140+ / Chrome 141+), `node:test`, `node:sqlite` (tests only), `fzstd`
(new runtime dependency).

**Spec:** `docs/superpowers/specs/2026-10-19-my-words-design.md`

## Global Constraints

- No WebAssembly and no change to the extension's CSP.
- `fzstd` is the only new runtime dependency. It is bundled only into the My
  words page (`dist/mywords.js`), never into the background or content
  scripts.
- Storage key: `myWords` in `browser.storage.local`. Value: `[{ zh, pinyin,
  en, source }]`.
- Settings: `level: 0` means My words. `DEFAULT_SETTINGS.level` stays `7`.
- `zh` is 1–16 Han characters. `en`, `pinyin` and `source` are strings
  trimmed to 200 characters. The list is limited to 20,000 words.
- `setMyWords` is accepted only from extension pages
  (`src/background/guard.js` `PAGE_ONLY`).
- Collections are read in this order: `collection.anki21b`, then
  `collection.anki21`, then `collection.anki2`. A file whose only collection
  is the "Please update to the latest Anki version" stub is an error.
- HSK data is **not** used at level 0. The level-0 English comes only from
  the card's English and CC-CEDICT, with CC-CEDICT limited to the card's
  pronunciation when it has one.
- Match the existing code style: 2-space indent, single quotes, semicolons,
  small `h()` DOM builders, and a comment explaining *why* only where it isn't
  obvious.
- Tests run with `npm test`, which this plan changes to
  `node --experimental-sqlite --test 'test/unit/*.test.js'` (Node 23.2 needs
  the flag for `node:sqlite`).

## Review Focus

1. **Chinese split by inline HTML** (`<b>中</b>国`) must import as 中国, not
   中. *Pinned in Task 4 (`cleanField` test).*
2. **Importing a file that isn't an Anki deck** (a `.colpkg`, a renamed zip,

   *Pinned in Task 4 (`readApkg` rejects non-zip and zip-without-collection)
   and Task 8 (the page saves only after a successful parse).*
3. **Choosing 我的 with an empty list** must leave pages in English, with no

   with it swaps nothing).*
4. **Re-importing a deck with Add after editing a word's English** must keep

5. **A deck that mixes notetypes** (e.g. a Basic English card next to vocab

```js
// English glosses from dictionary definitions ("to live (somewhere); to stay"
// -> "live", "stay"). Shared by the HSK build (scripts/build-hsk.mjs) and My
// words (src/shared/mywords.js), so both clean definitions the same way.

// Function words: a sentence with these swapped is harder to read, not easier.
export const STOP = new Set(`a an the to of in on at by for with from and or but not no yes it its this that these
those he she they we you i me him her them us my your his our their is am are was were be been
being do does did have has had will would can could should may might must shall if so as than then
there here what which who whom whose when where why how all any some very just also too up down
out about into over after before again more most other such only own same few each both many much
one ok okay well get got make let`.split(/\s+/));

// Dictionary senses that aren't meanings a reader would know the word by.
export const SKIP_MEANING = /surname|variant of|abbr\.|used in|classifier|old name|archaic|dialect|literary|Taiwan pr/i;

/** English that can be matched in text: one to three plain words. */
export const GLOSS = /^[a-z]+(?:[ -][a-z]+){0,2}$/;

export function cleanGloss(gloss) {
  return gloss
    .replace(/\([^)]*\)/g, ' ')
    .replace(/\b(sth|sb|one's|oneself|someone|something)\b/g, ' ')
    .replace(/^\s*(to|a|an|the)\s+/i, '')
    .replace(/\s+/g, ' ')
    .trim();
}

/** Usable lowercase English keys in a definition list, in order, no repeats. */
export function glosses(text, { skip = null } = {}) {
  const out = [];
  for (const part of String(text ?? '').split(/[;,/]/)) {
    if (skip?.test(part)) continue;
    const en = cleanGloss(part).toLowerCase();
    if (GLOSS.test(en) && !STOP.has(en) && !out.includes(en)) out.push(en);
  }
  return out;
}
```

```js
// Builds small Anki-like files for tests: zips, zstd frames and SQLite
// databases shaped like Anki collections.

import { deflateRawSync } from 'node:zlib';

const encoder = new TextEncoder();
const bytesOf = (content) => (typeof content === 'string' ? encoder.encode(content) : content);

/** A zip with each entry stored (method 0) or deflated (method 8). CRCs are left 0. */
export function makeZip(files, { method = 8 } = {}) {
  const locals = [];
  const central = [];
  let offset = 0;
  for (const [name, content] of Object.entries(files)) {
    const raw = bytesOf(content);
    const data = method === 8 ? deflateRawSync(raw) : Buffer.from(raw);
    const nameBytes = Buffer.from(encoder.encode(name));
    const local = Buffer.alloc(30);
    local.writeUInt32LE(0x04034b50, 0);
    local.writeUInt16LE(20, 4);
    local.writeUInt16LE(method, 8);
    local.writeUInt32LE(data.length, 18);
    local.writeUInt32LE(raw.length, 22);
    local.writeUInt16LE(nameBytes.length, 26);
    const entry = Buffer.alloc(46);
    entry.writeUInt32LE(0x02014b50, 0);
    entry.writeUInt16LE(20, 4);
    entry.writeUInt16LE(20, 6);
    entry.writeUInt16LE(method, 10);
    entry.writeUInt32LE(data.length, 20);
    entry.writeUInt32LE(raw.length, 24);
    entry.writeUInt16LE(nameBytes.length, 28);
    entry.writeUInt32LE(offset, 42);
    locals.push(local, nameBytes, data);
    central.push(entry, nameBytes);
    offset += 30 + nameBytes.length + data.length;
  }
  const count = Object.keys(files).length;
  const end = Buffer.alloc(22);
  end.writeUInt32LE(0x06054b50, 0);
  end.writeUInt16LE(count, 8);
  end.writeUInt16LE(count, 10);
  end.writeUInt32LE(central.reduce((n, b) => n + b.length, 0), 12);
  end.writeUInt32LE(offset, 16);
  return new Uint8Array(Buffer.concat([...locals, ...central, end]));
}
```

```js
// Minimal zip reader for Anki .apkg files: stored and deflated entries only.
// Format: https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT

const EOCD_SIG = 0x06054b50;
const CENTRAL_SIG = 0x02014b50;
const LOCAL_SIG = 0x04034b50;

/** -> Map of entry name -> () => Promise<Uint8Array> (the entry's uncompressed bytes). */
export function readZip(buffer) {
  const bytes = buffer instanceof Uint8Array ? buffer : new Uint8Array(buffer);
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  let eocd = -1;
  // The end record is 22 bytes plus a comment of up to 65535 bytes.
  for (let i = bytes.length - 22; i >= Math.max(0, bytes.length - 22 - 0xffff); i--) {
    if (view.getUint32(i, true) === EOCD_SIG) {
      eocd = i;
      break;
    }
  }
  if (eocd < 0) throw new Error('Not a zip file');
  const count = view.getUint16(eocd + 10, true);
  let pos = view.getUint32(eocd + 16, true);
  if (count === 0xffff || pos === 0xffffffff) throw new Error('Zip64 archives are not supported');

  const decoder = new TextDecoder();
  const entries = new Map();
  for (let i = 0; i < count; i++) {
    if (pos + 46 > bytes.length || view.getUint32(pos, true) !== CENTRAL_SIG) throw new Error('Corrupt zip directory');
    const flags = view.getUint16(pos + 8, true);
    const method = view.getUint16(pos + 10, true);
    const size = view.getUint32(pos + 20, true); // compressed
    const nameLength = view.getUint16(pos + 28, true);
    const extraLength = view.getUint16(pos + 30, true);
    const commentLength = view.getUint16(pos + 32, true);
    const local = view.getUint32(pos + 42, true);
    const name = decoder.decode(bytes.subarray(pos + 46, pos + 46 + nameLength));
    pos += 46 + nameLength + extraLength + commentLength;
    if (size === 0xffffffff || local === 0xffffffff) throw new Error('Zip64 archives are not supported');
    entries.set(name, async () => {
      if (flags & 1) throw new Error(`${name} is encrypted`);
      if (view.getUint32(local, true) !== LOCAL_SIG) throw new Error('Corrupt zip entry');
      const start = local + 30 + view.getUint16(local + 26, true) + view.getUint16(local + 28, true);
      const data = bytes.subarray(start, start + size);
      if (method === 0) return data;
      if (method === 8) return inflate(data);
      throw new Error(`${name} uses an unsupported compression method (${method})`);
    });
  }
  return entries;
}

async function inflate(data) {
  const stream = new Blob([data]).stream().pipeThrough(new DecompressionStream('deflate-raw'));
  return new Uint8Array(await new Response(stream).arrayBuffer());
}
```

**Interfaces:**
- Produces: `openDb(bytes: Uint8Array): { tables(): string[], rows(name: string): Array<{ rowid: number | null, values: Array<null | number | bigint | string | Uint8Array> }> }`.
  - `values` are in stored column order. For ordinary tables that's
    declaration order, and an `INTEGER PRIMARY KEY` column reads as `null`
    (use `rowid` instead). For `WITHOUT ROWID` tables, the primary-key columns
    come first and `rowid` is `null`.
  - Integers outside ±2^53 come back as `bigint`.
- Produces (test helper): `sqliteBytes(sql: string, { pageSize?: number }): Uint8Array`.

```js
/** A SQLite database file made by running `sql`, as bytes. */
export function sqliteBytes(sql, { pageSize = 4096 } = {}) {
  const dir = mkdtempSync(join(tmpdir(), 'zhi-sqlite-'));
  try {
    const file = join(dir, 'db.sqlite');
    const db = new DatabaseSync(file);
    db.exec(`pragma page_size = ${pageSize};`);
    db.exec(sql);
    db.close();
    return new Uint8Array(readFileSync(file));
  } finally {
    rmSync(dir, { recursive: true, force: true });
  }
}
```

```js
// Minimal read-only SQLite reader, enough to read Anki collections: walks
// table and index B-trees (WITHOUT ROWID tables are index B-trees), follows
// overflow pages and decodes records. No SQL, no indexes: callers scan tables.
// Format: https://www.sqlite.org/fileformat2.html

const decoder = new TextDecoder();

/** Big-endian varint at bytes[pos] -> [value, length]. Exact up to 2^53. */
function varint(bytes, pos) {
  let value = 0;
  for (let i = 0; i < 8; i++) {
    const b = bytes[pos + i];
    value = value * 128 + (b & 0x7f);
    if (b < 0x80) return [value, i + 1];
  }
  return [value * 256 + bytes[pos + 8], 9];
}

// Bytes taken by serial types 0–9.
const SIZES = [0, 1, 2, 3, 4, 6, 8, 8, 0, 0];

/** A record (row payload) -> array of column values. */
function decodeRecord(buf) {
  const view = new DataView(buf.buffer, buf.byteOffset, buf.byteLength);
  const [headerSize, n] = varint(buf, 0);
  const types = [];
  for (let p = n; p < headerSize;) {
    const [type, k] = varint(buf, p);
    types.push(type);
    p += k;
  }
  let off = headerSize;
  return types.map((type) => {
    const at = off;
    if (type >= 12) {
      const size = (type - (type % 2 ? 13 : 12)) / 2;
      off += size;
      const data = buf.subarray(at, at + size);
      return type % 2 ? decoder.decode(data) : data.slice();
    }
    off += SIZES[type] ?? 0;
    switch (type) {
      case 0: return null;
      case 1: return view.getInt8(at);
      case 2: return view.getInt16(at);
      case 3: return view.getInt8(at) * 0x10000 + view.getUint16(at + 1);
      case 4: return view.getInt32(at);
      case 5: return view.getInt16(at) * 0x100000000 + view.getUint32(at + 2);
      case 6: {
        const big = view.getBigInt64(at);
        return big >= BigInt(Number.MIN_SAFE_INTEGER) && big <= BigInt(Number.MAX_SAFE_INTEGER) ? Number(big) : big;
      }
      case 7: return view.getFloat64(at);
      case 8: return 0;
      case 9: return 1;
      default: throw new Error(`Corrupt database: serial type ${type}`);
    }
  });
}

/**
 * Opens a database held in memory.
 * -> { tables(): string[], rows(name): Array<{ rowid, values }> }
 * `values` are in the stored column order: declaration order for ordinary
 * tables (an INTEGER PRIMARY KEY column is null there; use `rowid`), and
 * primary-key columns first for WITHOUT ROWID tables (whose `rowid` is null).
 */
export function openDb(bytes) {
  if (bytes.length < 100 || decoder.decode(bytes.subarray(0, 16)) !== 'SQLite format 3\0') {
    throw new Error('Not a SQLite database');
  }
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  const rawSize = view.getUint16(16);
  const pageSize = rawSize === 1 ? 65536 : rawSize;
  const usable = pageSize - bytes[20];
  const encoding = view.getUint32(56);
  if (encoding !== 0 && encoding !== 1) throw new Error('Only UTF-8 databases are supported');

  const pageStart = (n) => {
    const start = (n - 1) * pageSize;
    if (n < 1 || start + pageSize > bytes.length) throw new Error(`Corrupt database: no page ${n}`);
    return start;
  };

  // A cell's payload of `size` bytes starting at `pos`, joined with its overflow pages.
  function payload(pos, size, index) {
    const maxLocal = index ? Math.floor(((usable - 12) * 64) / 255) - 23 : usable - 35;
    if (size <= maxLocal) return bytes.subarray(pos, pos + size);
    const minLocal = Math.floor(((usable - 12) * 32) / 255) - 23;
    let local = minLocal + ((size - minLocal) % (usable - 4));
    if (local > maxLocal) local = minLocal;
    const out = new Uint8Array(size);
    out.set(bytes.subarray(pos, pos + local));
    let filled = local;
    let next = view.getUint32(pos + local);
    while (filled < size) {
      if (!next) throw new Error('Corrupt database: overflow chain too short');
      const start = pageStart(next);
      const n = Math.min(usable - 4, size - filled);
      out.set(bytes.subarray(start + 4, start + 4 + n), filled);
      filled += n;
      next = view.getUint32(start);
    }
    return out;
  }

  function* walk(n, depth = 0) {
    if (depth > 64) throw new Error('Corrupt database: B-tree too deep');
    const start = pageStart(n);
    const header = n === 1 ? 100 : start; // page 1 starts with the 100-byte file header
    const type = bytes[header];
    const cells = view.getUint16(header + 3);
    const interior = type === 0x02 || type === 0x05;
    const pointers = header + (interior ? 12 : 8);
    for (let i = 0; i < cells; i++) {
      const cell = start + view.getUint16(pointers + 2 * i);
      if (type === 0x0d) { // table leaf: size, rowid, payload
        const [size, a] = varint(bytes, cell);
        const [rowid, b] = varint(bytes, cell + a);
        yield { rowid, values: decodeRecord(payload(cell + a + b, size, false)) };
      } else if (type === 0x05) { // table interior: left child, key
        yield* walk(view.getUint32(cell), depth + 1);
      } else if (type === 0x0a) { // index leaf: size, payload
        const [size, a] = varint(bytes, cell);
        yield { rowid: null, values: decodeRecord(payload(cell + a, size, true)) };
      } else if (type === 0x02) { // index interior: left child, then this cell's own row
        yield* walk(view.getUint32(cell), depth + 1);
        const [size, a] = varint(bytes, cell + 4);
        yield { rowid: null, values: decodeRecord(payload(cell + 4 + a, size, true)) };
      } else {
        throw new Error(`Corrupt database: page ${n} has type ${type}`);
      }
    }
    if (interior) yield* walk(view.getUint32(header + 8), depth + 1);
  }

  const tables = new Map();
  for (const { values: [type, name, , rootpage] } of walk(1)) {
    if (type === 'table' && rootpage > 0) tables.set(name, rootpage);
  }
  return {
    tables: () => [...tables.keys()],
    rows(name) {
      if (!tables.has(name)) throw new Error(`No table named ${name}`);
      return [...walk(tables.get(name))];
    },
  };
}
```

```js
/** A zstd frame holding `data` in raw (uncompressed) blocks: valid input for any zstd decoder. */
export function zstdRaw(data) {
  const MAX = 128 * 1024;
  const size = Buffer.alloc(4);
  size.writeUInt32LE(data.length);
  // Magic, then a header: single segment, 4-byte content size.
  const parts = [Buffer.from([0x28, 0xb5, 0x2f, 0xfd, 0xa0]), size];
  for (let i = 0; i === 0 || i < data.length; i += MAX) {
    const chunk = data.subarray(i, i + MAX);
    const header = (chunk.length << 3) | (i + MAX >= data.length ? 1 : 0); // block type 0 = raw
    parts.push(Buffer.from([header & 0xff, (header >> 8) & 0xff, (header >> 16) & 0xff]), chunk);
  }
  return new Uint8Array(Buffer.concat(parts));
}

export const STUB_TEXT = 'Please update to the latest Anki version, then import the .colpkg/.apkg file again.';

const MID = 1700000000001; // notetype
const DID = 1700000000002; // deck
const SUB = 1700000000003; // subdeck holding the cards

const q = (s) => `'${String(s).replace(/'/g, "''")}'`;

/**
 * An Anki collection database. `modern` puts field names in a `fields` table
 * and decks in a `decks` table (Anki 2.1.50+); otherwise they're JSON in `col`.
 * Columns are in Anki's order; unused trailing columns are left out.
 */
export function makeCollection({ modern = false, deck = 'Chinese 1', fields = ['Hanzi', 'Pinyin', 'Meaning'], notes = [] } = {}) {
  const models = modern ? '' : JSON.stringify({ [MID]: { id: MID, name: 'Vocab', flds: fields.map((name, ord) => ({ name, ord })) } });
  const decks = modern ? '' : JSON.stringify({ 1: { id: 1, name: 'Default' }, [DID]: { id: DID, name: deck }, [SUB]: { id: SUB, name: `${deck}::L01` } });
  const sql = [
    'create table col (id integer primary key, crt integer, mod integer, scm integer, ver integer, dty integer, usn integer, ls integer, conf text, models text, decks text, dconf text, tags text);',
    'create table notes (id integer primary key, guid text, mid integer, mod integer, usn integer, tags text, flds text, sfld integer, csum integer, flags integer, data text);',
    'create table cards (id integer primary key, nid integer, did integer, ord integer);',
    `insert into col values (1, 0, 0, 0, 11, 0, 0, 0, '{}', ${q(models)}, ${q(decks)}, '{}', '{}');`,
  ];
  if (modern) {
    sql.push(
      'create table fields (ntid integer not null, ord integer not null, name text not null, config blob not null, primary key (ntid, ord)) without rowid;',
      'create table decks (id integer primary key not null, name text not null, mtime_secs integer, usn integer, common blob, kind blob);',
      ...fields.map((name, ord) => `insert into fields values (${MID}, ${ord}, ${q(name)}, x'');`),
      `insert into decks values (1, 'Default', 0, 0, x'', x''), (${DID}, ${q(deck)}, 0, 0, x'', x''), (${SUB}, ${q(`${deck}\x1fL01`)}, 0, 0, x'', x'');`,
    );
  }
  notes.forEach((values, i) => {
    sql.push(
      `insert into notes values (${i + 1}, 'g${i}', ${MID}, 0, 0, '', ${q(values.join('\x1f'))}, ${q(values[0])}, 0, 0, '');`,
      `insert into cards values (${i + 1}, ${i + 1}, ${SUB}, 0);`,
    );
  });
  return sqliteBytes(sql.join('\n'));
}

/**
 * An .apkg. Modern: zstd collection.anki21b plus the stub collection.anki2,
 * like current Anki exports. Legacy: a plain collection.anki2.
 * stubOnly: just the stub, as if the real collection were missing.
 */
export function makeApkg({ modern = false, stubOnly = false, ...collection } = {}) {
  const stub = () => makeCollection({ fields: ['Front', 'Back'], notes: [[STUB_TEXT, '']] });
  const files = {};
  if (stubOnly) {
    files['collection.anki2'] = stub();
  } else if (modern) {
    files['collection.anki2'] = stub();
    files['collection.anki21b'] = zstdRaw(makeCollection({ ...collection, modern: true }));
    files.meta = new Uint8Array([8, 3]);
  } else {
    files['collection.anki2'] = makeCollection(collection);
  }
  files.media = '{}';
  return makeZip(files);
}
```

```js
// Reads the words of an Anki deck (.apkg): the Chinese, pinyin and English
// of every note. Handles decks generated by tools (collection.anki2), older
// Anki exports (collection.anki21) and current ones (collection.anki21b,
// zstd-compressed, with field names in a `fields` table).

import { decompress } from 'fzstd';
import { readZip } from './zip.js';
import { openDb } from './sqlite.js';

const COLLECTIONS = ['collection.anki21b', 'collection.anki21', 'collection.anki2'];
// Current Anki also writes a collection.anki2 holding one note with this text,
// for older Anki versions to show.
const STUB = /^Please update to the latest Anki version/;

const HAN = /\p{Script=Han}/u;
const HAN_RUN = /\p{Script=Han}+/u;
const ZH_NAME = /^(hanzi|simplified|chinese|word|front|expression)$/i;
const EN_NAME = /^(meaning|english|definition|translation|back|gloss)$/i;
const PINYIN_NAME = /^pinyin$/i;

// Column positions in Anki's tables.
const NOTE = { mid: 2, flds: 6 };
const CARD = { did: 2 };
const COL = { models: 9, decks: 10 };

const ENTITIES = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'", nbsp: ' ' };

function decodeEntities(text) {
  return text.replace(/&(#x[0-9a-f]+|#\d+|[a-z]+);/gi, (m, e) => {
    if (e[0] !== '#') return ENTITIES[e.toLowerCase()] ?? m;
    const code = e[1] === 'x' || e[1] === 'X' ? parseInt(e.slice(2), 16) : parseInt(e.slice(1), 10);
    return code > 0 && code <= 0x10ffff ? String.fromCodePoint(code) : m;
  });
}

/** A field's HTML -> plain text: no tags, entities or [sound:…] references. */
export function cleanField(html) {
  return decodeEntities(String(html ?? '')
    .replace(/\[sound:[^\]]*\]/g, ' ')
    .replace(/<(br|div|p|li)\b[^>]*>/gi, '; ') // line breaks separate meanings
    .replace(/<[^>]*>/g, '')) // inline tags don't: <b>中</b>国 is 中国
    .replace(/\s+/g, ' ')
    .replace(/^[;\s]+|[;\s]+$/g, '');
}

const hanShare = (text) => {
  const chars = [...text.replace(/\s/g, '')];
  return chars.length ? chars.filter((c) => HAN.test(c)).length / chars.length : 0;
};

/** Which field holds the Chinese, pinyin and English, by name, else by content. */
function pickFields(names, values) {
  const named = (re, ok = () => true) => names.findIndex((name, i) => re.test(name ?? '') && ok(i));
  let zh = named(ZH_NAME, (i) => HAN.test(values[i] ?? ''));
  if (zh < 0) zh = values.findIndex((v) => hanShare(v) > 0.5);
  return { zh, pinyin: named(PINYIN_NAME), en: named(EN_NAME, (i) => i !== zh) };
}

/** Notetype id -> field names by position. */
function fieldNames(db) {
  const names = new Map();
  if (db.tables().includes('fields')) {
    for (const { values: [ntid, ord, name] } of db.rows('fields')) {
      if (!names.has(ntid)) names.set(ntid, []);
      names.get(ntid)[ord] = name;
    }
  }
  if (!names.size) {
    const models = db.rows('col')[0]?.values[COL.models];
    for (const model of Object.values(JSON.parse(models || '{}'))) {
      names.set(Number(model.id), [...model.flds].sort((a, b) => a.ord - b.ord).map((f) => f.name));
    }
  }
  return names;
}

/** Name of the top-level deck holding most of the cards ("Chinese 1" for "Chinese 1::L01"). */
function deckName(db) {
  const counts = new Map();
  for (const { values } of db.rows('cards')) counts.set(values[CARD.did], (counts.get(values[CARD.did]) ?? 0) + 1);
  const [top] = [...counts].sort((a, b) => b[1] - a[1])[0] ?? [];
  if (top == null) return '';
  let name = '';
  if (db.tables().includes('decks')) {
    name = db.rows('decks').find((r) => r.rowid === top)?.values[1] ?? '';
  } else {
    name = JSON.parse(db.rows('col')[0]?.values[COL.decks] || '{}')[top]?.name ?? '';
  }
  return String(name).split(/::|\x1f/)[0];
}

/** -> { deck, words: [{ zh, pinyin, en }], skipped: [string] }, or null for the stub. */
function readCollection(db) {
  const notes = db.rows('notes');
  const firstField = (note) => cleanField(String(note.values[NOTE.flds] ?? '').split('\x1f')[0]);
  if (notes.length === 1 && STUB.test(firstField(notes[0]))) return null;

  const names = fieldNames(db);
  const words = [];
  const skipped = [];
  const seen = new Set();
  for (const note of notes) {
    const values = String(note.values[NOTE.flds] ?? '').split('\x1f').map(cleanField);
    const field = pickFields(names.get(note.values[NOTE.mid]) ?? [], values);
    const zh = field.zh >= 0 ? HAN_RUN.exec(values[field.zh])?.[0] : undefined;
    if (!zh) {
      skipped.push(firstField(note).slice(0, 20));
      continue;
    }
    if (seen.has(zh)) continue;
    seen.add(zh);
    words.push({ zh, pinyin: values[field.pinyin] ?? '', en: values[field.en] ?? '' });
  }
  return { deck: deckName(db), words, skipped };
}

/** An .apkg file's bytes -> { deck, words, skipped }. */
export async function readApkg(buffer) {
  const zip = readZip(buffer);
  for (const name of COLLECTIONS) {
    if (!zip.has(name)) continue;
    let bytes = await zip.get(name)();
    if (name.endsWith('b')) bytes = decompress(bytes);
    const result = readCollection(openDb(bytes));
    if (result) return result;
  }
  throw new Error('No Anki collection in this file. Export the deck from Anki as "Anki Deck Package (*.apkg)".');
}
```

```js
// My words: the user's own list of Chinese words (imported from Anki decks or
// added by hand), and the English -> Chinese map that level 0 swaps with.
// Pure functions; the background and the My words page share them.
//
// A word stands for every meaning you could know it by, not only the ones
// its flashcard lists: the card's English plus every CC-CEDICT definition
// for the card's pronunciation (中 zhōng: middle, among, during…, but not
// zhòng: to hit). As at the HSK levels, a swap also needs the Chinese to
// appear in Apple's translation of the sentence (see diglot.js).

import { toMarks } from './pinyin.js';
import { glosses, SKIP_MEANING } from './gloss.js';
import { MY_LEVEL } from './diglot.js';

export const MAX_MY_WORDS = 20_000;
const MAX_TEXT = 200;
const HAN_WORD = /^\p{Script=Han}{1,16}$/u;

const text = (value) => (typeof value === 'string' ? value.trim().slice(0, MAX_TEXT) : '');

/** A stored word record, or null if `w` isn't one. */
export function cleanMyWord(w) {
  if (!w || typeof w !== 'object' || typeof w.zh !== 'string') return null;
  const zh = w.zh.trim();
  if (!HAN_WORD.test(zh)) return null;
  return { zh, pinyin: text(w.pinyin), en: text(w.en), source: text(w.source) };
}

/** Valid records only, first of each word kept, at most MAX_MY_WORDS. */
export function cleanMyWords(list) {
  if (!Array.isArray(list)) return [];
  const seen = new Set();
  const out = [];
  for (const w of list) {
    const clean = cleanMyWord(w);
    if (!clean || seen.has(clean.zh)) continue;
    seen.add(clean.zh);
    out.push(clean);
    if (out.length === MAX_MY_WORDS) break;
  }
  return out;
}

/**
 * Imports `incoming` words. 'add' keeps every existing word as it is
 * (including edited English); 'replace' starts from an empty list.
 * -> { words, added, existing }
 */
export function mergeWords(list, incoming, mode) {
  const words = mode === 'replace' ? [] : [...list];
  const have = new Set(words.map((w) => w.zh));
  let added = 0;
  let existing = 0;
  for (const w of incoming) {
    if (have.has(w.zh)) {
      existing++;
      continue;
    }
    have.add(w.zh);
    words.push(w);
    added++;
  }
  return { words, added, existing };
}

/** Adds a word by hand, or updates its English if it's already listed. Null if `zh` isn't a word. */
export function addWord(list, { zh, en }) {
  const word = cleanMyWord({ zh, en });
  if (!word) return null;
  if (list.some((w) => w.zh === word.zh)) return editWord(list, word.zh, word.en);
  return [...list, word];
}

export const removeWord = (list, zh) => list.filter((w) => w.zh !== zh);

export const editWord = (list, zh, en) => list.map((w) => (w.zh === zh ? { ...w, en: text(en) } : w));

const normPinyin = (pinyin) => toMarks(pinyin).normalize('NFC').toLowerCase().replace(/[\s'’·-]/g, '');

/**
 * CC-CEDICT entries for the card's pronunciation ("zhōng" or "zhong1").
 * All entries when there's no card pinyin or none matches (e.g. a typo).
 */
export function readingEntries(entries, pinyin) {
  if (!pinyin) return entries;
  const want = normPinyin(pinyin);
  const same = entries.filter((e) => normPinyin(e.pinyin) === want);
  return same.length ? same : entries;
}

/**
 * The level-0 word map, shaped like the HSK one (diglot.js parseWordMap):
 * lowercase English -> [{ zh, level: 0 }], longer Chinese words first.
 * `entriesFor(zh)` returns CC-CEDICT entries [{ pinyin, defs }].
 */
export function buildMyWordMap(words, entriesFor) {
  const map = new Map();
  const add = (en, zh) => {
    if (!map.has(en)) map.set(en, []);
    const list = map.get(en);
    if (!list.some((c) => c.zh === zh)) list.push({ zh, level: MY_LEVEL });
  };
  for (const w of words) {
    for (const en of glosses(w.en)) add(en, w.zh);
    for (const entry of readingEntries(entriesFor(w.zh), w.pinyin)) {
      for (const en of glosses(entry.defs, { skip: SKIP_MEANING })) add(en, w.zh);
    }
  }
  for (const list of map.values()) list.sort((a, b) => b.zh.length - a.zh.length);
  return map;
}
```

```js
// only some words are swapped into Chinese: HSK words up to the level (1–6),
```

- [ ] **Step 4: Create `src/mywords/mywords.js`**

```js
// My words page: import Anki decks, and add, edit and remove the words that
// the 我的 reading level swaps into Chinese.

import { readApkg } from '../shared/anki.js';
import { mergeWords, addWord, removeWord, editWord, readingEntries } from '../shared/mywords.js';
import { syllables } from '../shared/pinyin.js';
import { sendMessage as send } from '../shared/messaging.js';

const $ = (id) => document.getElementById(id);

let words = [];
const dict = new Map(); // zh -> CC-CEDICT entries [{ pinyin, defs }] ([] if not found)

function h(tag, props = {}, ...children) {
  const node = Object.assign(document.createElement(tag), props);
  node.append(...children.filter((c) => c != null));
  return node;
}

function pinyinNode(numbered) {
  const span = h('span');
  syllables(numbered).forEach((s, i) => {
    if (i) span.append(' ');
    span.append(h('span', { className: `zhi-t${s.tone || 5}`, textContent: s.text }));
  });
  return span;
}

async function entries(zh) {
  if (!dict.has(zh)) {
    const match = await send({ type: 'lookup', text: zh }).catch(() => null);
    dict.set(zh, match?.word === zh ? match.entries : []);
  }
  return dict.get(zh);
}

/** Lowercase text without tone marks, for search. */
const fold = (s) => s.normalize('NFD').replace(/\p{M}/gu, '').toLowerCase();

function haystack(w) {
  const py = (dict.get(w.zh) ?? []).map((e) => e.pinyin.replace(/\d/g, '')).join(' ');
  return fold(`${w.zh} ${w.pinyin} ${py} ${w.en}`);
}

async function save(next) {
  await send({ type: 'setMyWords', words: next });
  words = next;
  render();
}

function editCell(td, w) {
  if (td.querySelector('input')) return;
  const input = h('input', { value: w.en });
  input.setAttribute('aria-label', `English for ${w.zh}`);
  let cancelled = false;
  input.addEventListener('keydown', (e) => {
    if (e.key === 'Enter') input.blur();
    if (e.key === 'Escape') {
      cancelled = true;
      input.blur();
    }
  });
  input.addEventListener('blur', () => {
    if (!cancelled && input.value.trim() !== w.en) save(editWord(words, w.zh, input.value));
    else render();
  });
  td.replaceChildren(input);
  input.focus();
}

function row(w) {
  const entry = readingEntries(dict.get(w.zh) ?? [], w.pinyin)[0];
  const en = h('td', { className: 'en', textContent: w.en || '—', title: 'Click to edit' });
  en.addEventListener('click', () => editCell(en, w));
  const remove = h('button', { className: 'icon', textContent: '✕', title: `Remove ${w.zh}` });
  remove.addEventListener('click', () => save(removeWord(words, w.zh)));
  return h('tr', {},
    h('td', { className: 'w', textContent: w.zh }),
    h('td', { className: 'py' }, entry ? pinyinNode(entry.pinyin) : w.pinyin),
    en,
    h('td', { className: 'src', textContent: w.source || 'added by you' }),
    h('td', { className: 'act' }, remove));
}

function render() {
  const query = fold($('query').value.trim());
  const list = query ? words.filter((w) => haystack(w).includes(query)) : words;
  $('rows').replaceChildren(...list.map(row));
  const total = `${words.length} word${words.length === 1 ? '' : 's'}`;
  $('count').textContent = list.length === words.length ? total : `${list.length} of ${total}`;
  $('removeAll').disabled = !words.length;
  const empty = $('empty');
  empty.hidden = list.length > 0;
  empty.textContent = words.length ? 'No words match.' : 'No words yet. Import an Anki deck or add words above.';
}

async function load() {
  ({ myWords: words = [] } = await browser.storage.local.get('myWords'));
  render();
  await Promise.all(words.map((w) => entries(w.zh))); // pinyin and search
  render();
}

$('importApkg').addEventListener('change', async (e) => {
  const file = e.target.files[0];
  e.target.value = '';
  if (!file) return;
  const mode = document.querySelector('input[name=mode]:checked').value;
  const note = $('importNote');
  note.textContent = `Reading ${file.name}…`;
  try {
    const deck = await readApkg(await file.arrayBuffer());
    const source = deck.deck || file.name.replace(/\.apkg$/i, '');
    if (mode === 'replace' && words.length
      && !confirm(`Replace all ${words.length} words, including words you added by hand?`)) {
      note.textContent = '';
      return;
    }
    const merged = mergeWords(words, deck.words.map((w) => ({ ...w, source })), mode);
    await save(merged.words);
    const parts = [`Added ${merged.added} new word${merged.added === 1 ? '' : 's'} from ${source}`];
    if (merged.existing) parts.push(`${merged.existing} already in your list`);
    if (deck.skipped.length) {
      parts.push(`${deck.skipped.length} skipped (no Chinese): ${deck.skipped.slice(0, 5).join(', ')}${deck.skipped.length > 5 ? ', …' : ''}`);
    }
    note.textContent = parts.join(' · ');
    load();
  } catch (err) {
    note.textContent = `Import failed: ${err.message}`;
  }
});

$('addZh').addEventListener('change', async () => {
  const zh = $('addZh').value.trim();
  const found = zh ? await entries(zh) : [];
  // Prefer a real meaning over a "surname X" entry.
  const first = found.find((e) => !/^surname/i.test(e.defs)) ?? found[0];
  $('addPinyin').replaceChildren(first ? pinyinNode(first.pinyin) : '');
  if (first && !$('addEn').value.trim()) $('addEn').value = first.defs;
});

$('addForm').addEventListener('submit', async (e) => {
  e.preventDefault();
  const zh = $('addZh').value.trim();
  const next = addWord(words, { zh, en: $('addEn').value });
  if (!next) {
    $('addNote').textContent = 'Enter a word in Chinese characters (up to 16).';
    return;
  }
  const updated = words.some((w) => w.zh === zh);
  await save(next);
  $('addNote').textContent = updated ? `Updated ${zh}.` : `Added ${zh}.`;
  $('addZh').value = '';
  $('addEn').value = '';
  $('addPinyin').replaceChildren();
  load();
});

$('removeAll').addEventListener('click', () => {
  if (!confirm(`Remove all ${words.length} words from My words?`)) return;
  save([]);
});

$('query').addEventListener('input', render);
document.addEventListener('visibilitychange', () => { if (!document.hidden) load(); });

load();
```
